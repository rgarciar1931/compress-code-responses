# PHPStorm + GitHub Copilot

PHPStorm's GitHub Copilot plugin reads the same instruction files as VS Code and Copilot CLI:

1. **Repository-wide**: `.github/copilot-instructions.md` (generated by `npm run install-skill`)
2. **Path-specific**: `.github/instructions/compress-code-responses.instructions.md`

## Setup

1. Clone or add this repo (or run `npm run install-skill` in a project that vendors these files).
2. Enable **GitHub Copilot** and **custom instructions** in PHPStorm (Settings → Tools → GitHub Copilot).
3. Open the project root so Copilot loads `.github/copilot-instructions.md`.

## Post-response formatting

Copilot does not run shell commands automatically. After accepting AI edits, run:

```bash
npm run format -- path/to/changed/files
```

Or bind an External Tool in PHPStorm to `npm run format -- $FilePath$`.
